# Laboratório Web — Semana 43

**Professor(a):** Sinval Silva Júnior  
**Componente Curricular:** Laboratório WEB  
**Turma(s):** 3º Ano Integral  
**Período previsto:** 19/10 a 23/10 (Semana 43)

## CONTEÚDO / TEMA DA AULA

Quinta-feira (22/10, 08:40h — prática): acompanhamento de versões de código com Git. Sexta-feira (23/10, 14:10h — prática): construção da interface e interação de um jogo web sobre cores e tons.

## HABILIDADES (BNCC)

(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Acompanhar versões de um projeto por meio do histórico e das diferenças entre alterações; construir e testar interfaces web interativas com organização visual e instruções compreensíveis.

## DESENVOLVIMENTO DAS AULAS (2 aulas)

### Aula 1 (Quinta-feira, 22/10, 08:40h - Laboratório de Informática / Prática):

Descrição da aula: abrir o repositório do projeto, observar status, histórico e diferenças com git status, git log e git diff. Identificar qual arquivo foi alterado em cada etapa e criar um commit com mensagem clara. Em um exercício seguro, comparar uma versão anterior sem apagar o trabalho atual; esclarecer dúvidas específicas de acompanhamento de versões.

### Aula 2 (Sexta-feira, 23/10, 14:10h - Laboratório de Informática / Prática):

Descrição da aula: implementar a interface do jogo de cores: instrução, cor de referência, opções de tons, retorno textual para acerto/erro e pontuação ou rodada. Utilizar CSS para diferenciar tons e organizar as opções; incluir identificação textual para que a interação não dependa exclusivamente de perceber a cor. Testar a interface com colegas e ajustar instruções ou disposição dos elementos.

## AVALIAÇÃO

Aula 1: leitura do histórico/diff e commit identificável. Aula 2: jogo navegável, feedback compreensível e opções apresentadas de forma organizada.

## RECOMPOSIÇÃO DE APRENDIZAGEM

Fornecer um repositório de treino com poucas alterações e orientar status, log e diff antes de criar um commit. Para o jogo, entregar um HTML/CSS inicial com os espaços da interface definidos.

## OBSERVAÇÕES

As operações de restauração devem ser demonstradas em cópia ou ramo de exercício para preservar o trabalho do aluno. A variação de telas e condições de visualização deve ser discutida como fator de percepção dos tons.
