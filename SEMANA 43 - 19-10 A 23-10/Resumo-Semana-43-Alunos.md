# Semana 43 — Desenvolvimento, Git e jogo das cores

Durante a semana, vamos trabalhar com qualidade de software, desenvolvimento web, pesquisa para a Feira de Ciências, finalização de exercícios, Git/GitHub, funções JavaScript e acompanhamento de versões. Na sexta-feira, vamos criar e testar um jogo sobre cores e tons.

## Segunda-feira — qualidade e desenvolvimento web

- **Banco de Dados (07:00):** preparar uma prática de qualidade de software, definindo critérios e casos de teste.
- **Banco de Dados (13:20):** aprimorar uma funcionalidade web e testar entradas e resultados.
- **Rede (14:10):** observar o carregamento de um site e investigar recursos que não aparecem.
- **Programação Web II (15:15):** desenvolver e testar uma funcionalidade, organizando a lógica em funções.

## Terça-feira — Feira de Ciências e dúvidas

- **Laboratório de Hardware (09:45):** coletar e organizar informações para o projeto da Feira de Ciências.
- **Laboratório de Software (10:35):** finalizar exercícios e tirar dúvidas sobre Git e GitHub.

## Quarta-feira — funções e versões

- **Laboratório de Hardware (13:20):** praticar funções JavaScript e registrar uma melhoria usando Git.
- **Rede (14:10 e 15:15):** acompanhar a comunicação entre o repositório local e o GitHub e investigar problemas de sincronização.

## Quinta-feira — interface e histórico

- **Design (07:00):** identificar e corrigir dificuldades visuais na interface.
- **Laboratório Web (08:40):** consultar histórico e diferenças entre versões com Git.

## Sexta-feira — jogo sobre cores

- **Programação Web II (13:20):** criar a lógica do jogo usando funções.
- **Laboratório Web (14:10):** montar a interface, as opções de tons e o retorno ao jogador.
- **Laboratório de Software (15:15):** testar o jogo e registrar melhorias.

Vamos observar como tons parecidos podem parecer diferentes conforme a tela e as condições de visualização, e como cada pessoa pode perceber as cores de uma forma própria. Por isso, o jogo também terá instruções e indicações em texto, sem depender apenas da cor.
