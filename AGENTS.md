# Contexto do Projeto - 3INT

## Horários de Aula
O arquivo com os horários das aulas está em `referencias/horarios.md`. Consulte-o sempre que precisar saber os horários ou disciplinas do curso.

## Ementas das Disciplinas
O arquivo com as ementas, objetivos e bibliografias de cada disciplina está em `referencias/ementa.md`. Consulte-o sempre que precisar de detalhes sobre conteúdo programático, objetivos de aprendizagem ou referências bibliográficas.

## READMEs por pasta
Toda pasta do repositório deve conter um `README.md` descrevendo o conteúdo daquela pasta. Ao criar uma nova pasta ou adicionar arquivos relevantes a uma pasta existente, crie ou atualize o `README.md` correspondente. Mantenha também um `README.md` geral na raiz do projeto, com visão geral do repositório e links para os READMEs de cada pasta.

## Resumo semanal
Toda pasta de semana (ex.: `SEMANA XX - DD-MM A DD-MM`) deve conter um resumo da semana, para repassar aos alunos. Ao criar ou fechar uma semana, crie/atualize esse resumo com os conteúdos abordados.
