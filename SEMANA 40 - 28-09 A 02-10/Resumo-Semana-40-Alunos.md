# 📚 Resumo da Semana 40 (28/09 a 02/10) — 3º INT

Semana com quatro frentes de conteúdo: **Introdução ao Excel**, **Imersão HTML+CSS+JS**,
**Introdução a Funções** (que fecha o conteúdo teórico de JavaScript do curso) e **Rede de
Computadores** (aulas leves e dinâmicas conectadas ao resto da semana). Todas as manhãs são
teóricas (slides + resumo para copiar no caderno + um exercício sem computador); todas as
tardes são práticas, no computador.

## 📊 Segunda-feira — Introdução ao Excel (parte 1)

**Banco de Dados (07:00, teoria):** planilha, linha (registro), coluna (campo) e célula
(valor), tipos de dado. Exercício no caderno: organizar dados soltos em uma tabela.

**Banco de Dados (13:20, prática):** montagem de uma planilha real de organização de
projeto no computador.

**Rede de Computadores (14:10):** dinâmica "corrente de dados" — a turma vira uma fila
representando Cliente, Rede, Servidor e Banco de Dados/Planilha, passando um "pedido" de
mão em mão (ex.: peso e altura para o IMC) e trazendo a resposta de volta.

**Programação Web II (15:15, prática):** uso da planilha do projeto para planejar o
protótipo do site da turma (sem conteúdo novo de JavaScript).

## 🔧 Terça-feira — Excel (parte 2) e início da Imersão HTML+CSS+JS (parte 1)

**Laboratório de Hardware (09:45, teoria):** fórmulas de soma, média e contagem, e
cronograma de projeto. Exercício no caderno: calcular à mão o total de horas de um projeto.

**Laboratório de Software (10:35, teoria):** `document.getElementById` e `.value` — como o
JavaScript "pega" um elemento do HTML e lê o que foi digitado. Exercício no caderno:
identificar elementos pelo `id`.

## 🖥️ Quarta-feira — Prática de Excel e Rede

**Laboratório de Hardware (13:20, prática):** cronograma de projeto completo no computador,
com as fórmulas de soma e média funcionando de verdade.

**Rede de Computadores (14:10):** conversa dirigida sobre o modelo Cliente-Servidor,
ligando os protótipos da turma (getElementById/.innerHTML) a um pedido real que viaja pela
rede até um servidor e um banco de dados — com retomada leve do modelo OSI/TCP-IP visto na
Semana 39.

**Rede de Computadores (15:15):** em grupos, cartaz desenhando o caminho completo de um dado
do protótipo (ex.: cálculo de IMC) — do `<input>` até o banco de dados e de volta à tela.

## ⚙️ Quinta-feira — Imersão HTML+CSS+JS (parte 2) e Introdução a Funções

**Design (07:00, teoria):** `.innerHTML` e `.innerHTML +=` — escrever/alterar conteúdo do
HTML via JavaScript. Exercício no caderno: prever o resultado na tela sem rodar o código
(tracing).

**Laboratório Web (08:40, teoria):** Introdução a Funções — declaração, parâmetros e
`return`. **Última aula teórica de JavaScript do curso!** Exercício no caderno: calcular à
mão o resultado de uma função para diferentes valores de entrada.

## 🚀 Sexta-feira — Prática de HTML+CSS+JS e de Funções

**Programação Web II (13:20, prática):** prática completa juntando `getElementById`,
`.value` e `.innerHTML` — um input que vira item de uma lista na tela.

**Laboratório Web (14:10, prática):** exercícios 1 a 5 da Lista de Funções.

**Laboratório de Software (15:15, prática):** exercícios 6 a 10 da Lista de Funções.
