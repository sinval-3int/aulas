# Prompts — Semana 40

Material de apoio para gerar slides no NotebookLM: uma única fonte de conteúdo para a semana
toda, mais um prompt específico para cada uma das 5 aulas teóricas.

## Conteúdo

- **[Fonte-Semana-40.md](Fonte-Semana-40.md)** — Fonte única: reúne o conteúdo de quadro de todas as aulas da semana (Excel partes A e B, Imersão HTML+CSS+JS partes C e D, Funções parte E). É este o arquivo a subir no NotebookLM.
- **[BancoDados/](BancoDados/README.md)** — Prompts das aulas de Introdução ao Excel (partes A e B).
- **[ImersaoHtmlCssJs/](ImersaoHtmlCssJs/README.md)** — Prompts das aulas de Imersão HTML+CSS+JS (partes C e D).
- **[Funcoes/](Funcoes/README.md)** — Prompt da aula de Introdução a Funções (parte E).

## Observações

- Cada prompt indica qual PARTE (A a E) de `Fonte-Semana-40.md` usar como base dos slides daquela aula.
- Os planejamentos de aula (com data, horário, habilidades BNCC e avaliação) ficam em [`../Planejamento/`](../Planejamento/).
