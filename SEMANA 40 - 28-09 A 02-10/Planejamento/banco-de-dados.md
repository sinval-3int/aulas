(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Organizar dados em formato tabular (linhas e colunas), reconhecendo a relação entre planilha e tabela de banco de dados.

DESENVOLVIMENTO DAS AULAS (2 aulas)

Aula 1 (Segunda-feira, 07:00h - Sala de Aula / Expositiva, com slides):
Resumo para o quadro (para cópia dos alunos):
"1. Planilha = conjunto de tabelas (uma tabela por aba).
2. Linha = registro (ex.: uma tarefa do projeto).
3. Coluna = campo/atributo (ex.: responsável, prazo, status).
4. Célula = valor de um campo em um registro.
5. Cada coluna deve ter um tipo consistente de dado (texto, número, data)."
Descrição da aula: Aula expositiva com slides apresentando o Excel/planilha eletrônica como ferramenta de organização de dados, sem uso do computador. Explicação do paralelo entre planilha e tabela de banco de dados (linha = registro, coluna = campo), usando como exemplo uma planilha de controle de projeto (nome da tarefa, responsável, prazo, status).
Exercício em sala (sem computador — dinâmica no papel): o professor lista no quadro 5 registros soltos e desorganizados (ex.: dados de tarefas de um projeto fictício: tarefa, responsável, prazo, status). Os alunos desenham no caderno uma tabela (linhas e colunas) e organizam esses dados corretamente, identificando qual é o campo e qual é o registro.

Aula 2 (Segunda-feira, 13:20h - Laboratório de Informática / Prática):
Descrição da aula: Aula prática — cada aluno monta no computador sua própria planilha de organização de projeto (pode ser o próprio projeto integrador da turma), aplicando linhas/colunas/células e ao menos duas fórmulas (soma, média). Fechamento com discussão: "o que uma planilha não resolve bem, e que um banco de dados resolve?" (dados repetidos, múltiplos usuários simultâneos, relações entre tabelas).

AVALIAÇÃO
Aula 1: correção coletiva do exercício de organização de dados no caderno. Aula 2: entrega da planilha de organização de projeto, verificando estrutura em linhas/colunas e uso de ao menos uma fórmula.

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade em separar campo de registro, refazer com eles o exemplo do quadro apontando explicitamente: "esta coluna é sempre a mesma informação sobre pessoas/tarefas diferentes" (campo) x "esta linha é tudo sobre uma tarefa só" (registro).

OBSERVAÇÕES:
Conteúdo novo (primeiro contato com Excel/planilhas na disciplina). Continua em Laboratório de Hardware (terça-feira, 09:45h) com fórmulas e organização de projeto (parte 2). Serve de base conceitual para os próximos conteúdos de Banco de Dados (tabelas, registros, campos).
