DESENVOLVIMENTO DAS AULAS (2 aulas)

Aula 1 (Quinta-feira, 08:40h - Sala de Aula / Expositiva, com slides):
Resumo para o quadro (para cópia dos alunos):
"1. function nomeDaFuncao(parametro1, parametro2) { bloco } — declara uma função.
2. Parâmetro é a variável que a função recebe; argumento é o valor enviado na chamada.
3. nomeDaFuncao(valor1, valor2); — chama (executa) a função com valores reais.
4. return valor; — devolve um resultado e encerra a função.
5. Uma função só roda quando é chamada — declarar não executa."
Descrição da aula: Aula expositiva com slides, sem computador, introduzindo a sintaxe de funções em JavaScript, motivada pelo problema de código repetido (o cálculo de IMC e o teste de aprovação, já escritos várias vezes nos protótipos). Exemplos em slides: function sem parâmetro, function com parâmetro e sem retorno, function com parâmetro e com `return`. Fechamento com o paralelo entre função em JS e função matemática (entrada → processamento → saída) e um panorama de que esta é a última aula teórica de JavaScript do curso — a partir daqui tudo é aplicação do que já foi visto.
Exercício em sala (sem computador — dinâmica no papel): o professor escreve no quadro 2 funções já prontas com parâmetros e `return` (ex.: uma função de soma e uma função de cálculo de IMC). Para cada uma, dá 3 pares de valores diferentes de "chamada" e pede que os alunos calculem à mão, como se fossem a própria função, qual seria o resultado devolvido pelo `return` — uma tabela de entrada/saída, sem rodar código nenhum.

Aula 2 (Sexta-feira, 14:10h - Laboratório de Informática / Prática):
Descrição da aula: Prática no computador — alunos resolvem os exercícios 1 a 5 da Lista de Funções, do nível "sem parâmetro" até "com parâmetro e sem retorno", sempre ligando a função a um `<input>` e mostrando o resultado na tela. Professor circula atendendo dúvidas individuais.

AVALIAÇÃO
Aula 1: correção coletiva da tabela de entrada/saída (tracing de função no papel). Aula 2: acompanhamento da resolução dos exercícios 1 a 5, verificando declaração, parâmetros e uso do `return`.

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, começar pela reescrita literal de um trecho de código já existente (sem função) e, ao lado, a mesma lógica dentro de uma function, mostrando a diferença apenas na "moldura" do código.

OBSERVAÇÕES:
Aula 1: conteúdo novo, fecha o conteúdo teórico de JavaScript do curso. Aula 2: prática direta da teoria dada na Aula 1, com continuação em Laboratório de Software (sexta-feira, 15:15h, exercícios 6 a 10).
