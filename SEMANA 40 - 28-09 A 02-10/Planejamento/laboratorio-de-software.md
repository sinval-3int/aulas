CONTEÚDO / TEMA DA AULA
Terça-feira (10:35h — Manhã / Expositiva): Imersão HTML + CSS + JavaScript, parte 1 (teoria) — o que é o DOM, `document.getElementById` e `.value`, sem uso do computador. Sexta-feira (15:15h — Tarde / Prática): resolução dos exercícios 6 a 10 da Lista de Funções.

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Identificar, a partir de um trecho de HTML, qual elemento seria selecionado por `document.getElementById`, e reconhecer o papel de `.value` na leitura de dados digitados pelo usuário; declarar funções com `return` e reaproveitar a mesma função com valores diferentes.

DESENVOLVIMENTO DAS AULAS (2 aulas)
Aula 1 (Terça-feira, 10:35h - Sala de Aula / Expositiva, com slides):
Resumo para o quadro (para cópia dos alunos):
"1. HTML dá a estrutura da página; CSS dá a aparência; JavaScript dá o comportamento.
2. Todo elemento pode ter um id="..." único, que o identifica na página.
3. document.getElementById('id') — pega, em JavaScript, o elemento do HTML que tem aquele id.
4. .value — lê (ou escreve) o que está digitado dentro de um <input>."
Descrição da aula: Aula expositiva com slides, sem computador, aprofundando a tríade HTML+CSS+JS e apresentando `document.getElementById` e `.value` como a "ponte" entre o JavaScript e o HTML. Uso de trechos de código impressos/projetados (sem digitação em aula) para exemplificar.
Exercício em sala (sem computador — dinâmica no papel): o professor projeta/entrega um trecho de HTML impresso com 4-5 elementos diferentes, cada um com um `id` (ex.: `id="nomeInput"`, `id="resultado"`, `id="botaoEnviar"`). Ao lado de cada `document.getElementById('...')` escrito no quadro, os alunos escrevem no caderno qual elemento do HTML seria selecionado.

Aula 2 (Sexta-feira, 15:15h - Laboratório de Informática / Prática):
Descrição da aula: Continuação da prática de Funções iniciada em Laboratório Web (14:10h, mesmo dia). Alunos resolvem os exercícios 6 a 10 da Lista de Funções, do nível "com parâmetro e `return`" até "reaproveitando a mesma função". Fechamento da semana com uma função sendo chamada duas vezes com valores diferentes, mostrando os dois resultados na mesma página.

AVALIAÇÃO
Aula 1: correção coletiva do exercício de identificação de elementos por id. Aula 2: acompanhamento da resolução dos exercícios 6 a 10, verificando uso do `return` e reaproveitamento da função.

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade em relacionar o texto entre aspas do `id` com o texto entre aspas do `getElementById`, destacar com cores diferentes (quadro/slide) o mesmo texto nos dois lugares. Para dificuldade nos exercícios de função com `return`, retomar a tabela de entrada/saída feita no papel em Laboratório Web (quinta-feira).
