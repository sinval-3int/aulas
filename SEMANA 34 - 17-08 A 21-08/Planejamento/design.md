CONTEÚDO / TEMA DA AULA
Semana de avaliações. Aula 1 (quinta-feira, 07:00h) é a primeira metade da revisão de JavaScript (o que é JS, variáveis, prompt-sync, operadores).

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Consolidar os fundamentos de JavaScript (variáveis, operadores) preparando os alunos para avaliação objetiva.

DESENVOLVIMENTO DAS AULAS (1 aula)
Aula 1 (Quinta-feira, 07:00h - Sala de Aula / Revisão):
Resumo para o quadro (Para cópia dos alunos — primeira metade da Revisão 3, ver `Provas/Revisao-3-JavaScript.docx`):
"1. O que é JavaScript: linguagem interpretada, de tipagem dinâmica, criada pela Netscape em 1995. Roda no navegador. JS não é Java.
2. Variáveis e entrada de dados: var nome = valor; — não é preciso declarar o tipo. Módulo prompt-sync (require(\"prompt-sync\")()) lê o que o usuário digita no terminal.
3. Operadores: matemáticos (+ - * / % ++ --); comparação — atenção: = atribui um valor, == compara só o valor, === compara valor E tipo; lógicos (&& E, || OU, ! NÃO)."
Descrição da aula: Revisão oral e no quadro da primeira metade dos conteúdos de JavaScript, complementada pela Aula 1 de Laboratório Web (08:40h) no mesmo dia, preparando os alunos para a Prova 3 — JavaScript, aplicada na sexta-feira.

AVALIAÇÃO
Avaliação contínua através da participação na revisão. A avaliação com nota (Prova 3 — JavaScript) ocorre na sexta-feira, em Programação Web II, Laboratório Web e Laboratório de Software.

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, retomar individualmente a diferença entre `=`, `==` e `===` com exemplos escritos no quadro, um de cada vez.

OBSERVAÇÕES:
Semana de avaliações: sem conteúdo novo. Aula conecta diretamente com a Aula 1 de Laboratório Web (mesma manhã), que completa a Revisão 3 com os tópicos 4 a 6 (condicional, DOM/console, template literals). Sem vínculo com Media Queries ou com o protótipo pessoal nesta semana.
