DESENVOLVIMENTO DAS AULAS (2 aulas)
Aula 1 (Segunda-feira, 07:00h - Sala de Aula / Revisão):
Resumo para o quadro (Para cópia dos alunos — Revisão 1, ver `SEMANA 34 - 17-08 A 21-08/Provas/Revisao-1-Geral.docx`):
"1. Git: git add . → git commit -m '...' → git push (sem clone). git pull antes de começar. .gitignore evita subir node_modules. Atenção: git commit (não git comit), -m (não -msg).
2. Terminal e Node.js: cd navega entre pastas, ls/dir lista arquivos. node arquivo.js executa um script fora do navegador.
3. npm: npm init -y cria o package.json. npm install prompt-sync foi o módulo instalado em aula para ler o que o usuário digita no terminal.
4. Kanban: A Fazer → Fazendo → Feito.
5. Banco de Dados: coluna de tabela = variável, um valor por vez. WHERE filtra linhas — não apaga dados, não substitui o SELECT.
6. Hardware e Rede: CPU processa o script, RAM guarda as variáveis. Cabo conectado = true, desconectado = false. Aba Network mostra o Status (200 = sucesso); erros de conexão aparecem no console — são ferramentas diferentes."
Descrição da aula: Revisão oral e no quadro dos seis blocos de conteúdo acumulados nas Semanas 31 a 33, preparando os alunos para a Prova 1 — Geral, aplicada ainda hoje à tarde nos três últimos horários (Banco de Dados, Rede de Computadores e Programação Web II). Material de apoio: `Provas/Revisao-1-Geral.docx`.
