CONTEÚDO / TEMA DA AULA
Semana de avaliações. Aula 1 (terça-feira, 09:45h) é a primeira metade da revisão de HTML + CSS (tags estruturais, importação de CSS, títulos h1-h6). Aula 2 (quarta-feira, 13:20h) é a aplicação da Prova 2 — HTML + CSS.

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Consolidar os conceitos de estruturação semântica de páginas HTML e importação de arquivos CSS, preparando os alunos para avaliação objetiva.

DESENVOLVIMENTO DAS AULAS (2 aulas)
Aula 1 (Terça-feira, 09:45h - Sala de Aula / Revisão):
Resumo para o quadro (Para cópia dos alunos — primeira metade da Revisão 2, ver `Provas/Revisao-2-HTML-CSS.docx`):
"1. Tags estruturais/semânticas: header, nav, main, section, article, footer — cada tag tem uma função própria (nav agrupa links de navegação; p é parágrafo, não título).
2. Estrutura do projeto e importação do CSS: index.html + style.css + script.js na mesma pasta. <link rel=\"stylesheet\" href=\"arquivo.css\"> no <head> — o nome do arquivo tem que bater exatamente (maiúsculas, acentos, hífen/underline importam).
3. Títulos h1 a h6: <h1> é o título de maior destaque; o tamanho/peso tende a diminuir até <h6>. São tags de texto, não de imagem."
Descrição da aula: Revisão oral e no quadro da primeira metade dos conteúdos de HTML/CSS, complementada pela Aula 2 de Laboratório de Software (10:35h) no mesmo dia, preparando os alunos para a Prova 2 — HTML + CSS, aplicada na quarta-feira.

Aula 2 (Quarta-feira, 13:20h - Sala de Aula / Avaliação):
Descrição da aula: Aplicação da Prova 2 — HTML + CSS (10 questões objetivas), impressa a partir de `Provas/Prova-2-HTML-CSS.docx`. Prova individual, sem consulta, iniciada nesta aula e com continuidade em Rede de Computadores (14:10h e 15:15h) no mesmo dia.

AVALIAÇÃO
Participação na revisão (Aula 1) e na Prova 2 — HTML + CSS (Aula 2). Gabarito de correção em `Provas/Prova-2-HTML-CSS.docx`.

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, retomar individualmente as tags estruturais e a importação do CSS com um exemplo próprio do protótipo de cada aluno, tag por tag.

OBSERVAÇÕES:
Semana de avaliações: sem conteúdo novo. A Aula 1 conecta diretamente com a Aula 1 de Laboratório de Software (mesma manhã), que completa a Revisão 2 com os tópicos 4 a 6 (Box Model, seletores, script).
