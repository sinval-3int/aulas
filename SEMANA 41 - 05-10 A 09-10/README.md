# Semana 41 (05/10 a 09/10) — 3º Ano Integral

Semana dedicada a atividades práticas no laboratório de informática: pensamento em código e algoritmos, desenvolvimento web, revisão e aprimoramento de código. As aulas regulares de quinta-feira (08/10) são substituídas pelo simulado de redação do ENEM para os 1º, 2º e 3º anos.

## Cronograma

| Dia | Aulas e atividades |
|---|---|
| Segunda, 05/10 | Banco de Dados (07:00 e 13:20): modelar dados e construir um painel de tarefas; Rede (14:10): observar cliente, servidor local e requisições; Programação Web II (15:15): planejar algoritmo e implementar uma funcionalidade. |
| Terça, 06/10 | Laboratório de Hardware (09:45): preparar e organizar o ambiente de desenvolvimento; Laboratório de Software (10:35): localizar erros e aprimorar código existente. |
| Quarta, 07/10 | Laboratório de Hardware (13:20): implementar e revisar uma funcionalidade; Rede (14:10 e 15:15): rastrear requisições e diagnosticar problemas de conectividade/serviço no ambiente de desenvolvimento. |
| Quinta, 08/10 | Simulado de redação do ENEM para 1º, 2º e 3º anos. Substitui as aulas regulares de Design e Laboratório Web. Texto para o DED em [simulado-redacao-ded.md](Planejamento/simulado-redacao-ded.md). |
| Sexta, 09/10 | Programação Web II (13:20): integrar e demonstrar o painel; Laboratório Web (14:10): testar algoritmos e funcionalidades; Laboratório de Software (15:15): revisão final, documentação e apresentação das melhorias. |

## Projeto prático da semana

Cada aluno ou grupo evolui um site ou protótipo já iniciado. Como referência comum, os planos usam um **painel de tarefas** com inclusão, listagem, alteração de status e filtros. A implementação pode ser adaptada a outro projeto da turma, mantendo o foco em decompor problemas, escrever algoritmos, implementar, testar e melhorar o código.
