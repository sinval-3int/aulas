# Site — Loja da Teté

Site demonstrativo de uma página, com HTML semântico e arquivos separados de CSS e JavaScript.

## Arquivos

- `index.html` — home, catálogo, apresentação da loja, sacola e formulário de contato.
- `style.css` — identidade visual, contraste, foco de teclado e layout responsivo.
- `script.js` — lista de produtos, filtro, busca, sacola local e validação demonstrativa do formulário.
- `imagens/` — fotos locais reaproveitadas do projeto de aula da Loja da Teté.

## Abrir

Abra `index.html` no navegador. Para que `localStorage` funcione de forma consistente em todos os navegadores, você também pode servir esta pasta localmente, por exemplo com `python3 -m http.server 8000`, e abrir `http://localhost:8000`.

O catálogo e os valores são demonstrativos. Não existe pagamento, envio de pedidos ou conexão com banco de dados real.
