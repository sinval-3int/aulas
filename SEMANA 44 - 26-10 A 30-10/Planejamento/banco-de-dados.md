# Banco de Dados — Semana 44

**Professor(a):** Sinval Silva Júnior  
**Componente Curricular:** Banco de Dados  
**Turma(s):** 3º Ano Integral  
**Período previsto:** 26/10 a 30/10 (Semana 44)

## CONTEÚDO / TEMA DA AULA

Lançamento do trabalho final integrador; modelagem de dados e início de operações de persistência.

## HABILIDADES (BNCC)

(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Planejar a estrutura de dados de uma aplicação, relacionar registros e campos e executar operações de persistência compatíveis com o projeto final.

## DESENVOLVIMENTO DAS AULAS (2 aulas)

### Aula 1 (Segunda-feira, 26/10, 07:00h - Laboratório de Informática / Lançamento do trabalho final):

**Descrição da aula:** explicar a proposta do trabalho final integrador, retomando um projeto do primeiro ou do segundo trimestre para evoluí-lo até um site completo. Apresentar os requisitos de interface web, funções e listas JavaScript e banco de dados; explicar etapas, critérios de acompanhamento e organização das equipes. Cada equipe escolhe um projeto, identifica problema e usuários, lista funcionalidades e registra os dados que precisará armazenar.

Entregável: ficha inicial com equipe, projeto retomado, objetivo, funcionalidades previstas e dados principais.

### Aula 2 (Segunda-feira, 26/10, 13:20h - Laboratório de Informática / Prática):

**Descrição da aula:** transformar requisitos em modelo de dados, identificar entidades, campos e relações e planejar operações de cadastro, consulta, atualização e exclusão. Iniciar uma tabela ou operação no ambiente de banco de dados disponível e conferir a correspondência entre campos e formulário do site.

## AVALIAÇÃO

Aula 1: clareza do objetivo, escopo e dados necessários. Aula 2: coerência entre requisitos, modelo de dados e operações iniciadas.

## RECOMPOSIÇÃO DE APRENDIZAGEM

Disponibilizar um cadastro simples com campos e registros de exemplo. Apoiar a equipe na identificação de um único fluxo antes de ampliar o modelo.

## OBSERVAÇÕES

A primeira aula apresenta o trabalho final e inicia as equipes. O projeto continuará nas semanas seguintes; não é esperado que esteja concluído nesta semana.
