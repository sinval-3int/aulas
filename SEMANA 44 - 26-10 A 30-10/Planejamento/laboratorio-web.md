# Laboratório Web — Semana 44

**Professor(a):** Sinval Silva Júnior  
**Componente Curricular:** Laboratório WEB  
**Turma(s):** 3º Ano Integral  
**Período previsto:** 26/10 a 30/10 (Semana 44)

## CONTEÚDO / TEMA DA AULA

Integração de partes do site em equipe e validação de operações de dados no trabalho final.

## HABILIDADES (BNCC)

(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Desenvolver, em equipe, site que integre interface, programação e banco de dados; acompanhar etapas e testar fluxos implementados.

## DESENVOLVIMENTO DAS AULAS (2 aulas)

### Aula 1 (Quinta-feira, 29/10, 08:40h - Laboratório de Informática / Prática):

**Descrição da aula:** integrar partes existentes do site. Organizar tarefas e arquivos entre integrantes, combinar responsabilidades e registrar versão estável no Git antes de juntar alterações. Integrar uma tela ou funcionalidade de cada integrante e conferir se o projeto continua executando.

### Aula 2 (Sexta-feira, 30/10, 14:10h - Laboratório de Informática / Prática):

**Descrição da aula:** verificar o fluxo entre interface e dados. Testar cadastro, consulta, atualização e exclusão planejados pela equipe no ambiente disponível; observar entradas, respostas e mensagens de erro. Registrar o que está integrado e o que ainda depende de implementação.

## AVALIAÇÃO

Aula 1: contribuição integrada e versão de segurança registrada. Aula 2: fluxos de dados testados e pendências documentadas.

## RECOMPOSIÇÃO DE APRENDIZAGEM

Integrar primeiro uma tela e uma operação de dados com orientação; depois distribuir as tarefas restantes e repetir o processo.

## OBSERVAÇÕES

A integração com banco deve usar ambiente de servidor trabalhado pela turma, sem expor credenciais no JavaScript do navegador.
