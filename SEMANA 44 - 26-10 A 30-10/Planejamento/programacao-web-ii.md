# Programação Web II — Semana 44

**Professor(a):** Sinval Silva Júnior  
**Componente Curricular:** Programação WEB II  
**Turma(s):** 3º Ano Integral  
**Período previsto:** 26/10 a 30/10 (Semana 44)

## CONTEÚDO / TEMA DA AULA

Estrutura inicial do site e integração de funções, listas e dados no trabalho final.

## HABILIDADES (BNCC)

(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Integrar funções, listas, interface e persistência em banco de dados no desenvolvimento progressivo de um sistema web.

## DESENVOLVIMENTO DAS AULAS (2 aulas)

### Aula 1 (Segunda-feira, 26/10, 15:15h - Laboratório de Informática / Prática):

**Descrição da aula:** recuperar ou criar a estrutura inicial do projeto escolhido. Organizar HTML, CSS e JavaScript; implementar interação usando função e lista, como exibir registros ou validar dados do formulário. Registrar o que foi retomado dos projetos anteriores e o que será desenvolvido para completar o site.

### Aula 2 (Sexta-feira, 30/10, 13:20h - Laboratório de Informática / Prática):

**Descrição da aula:** integrar funções e listas com os fluxos de dados previstos. Ligar ações da interface às funções de cadastro e consulta e conferir a atualização da tela com dados reais ou de teste. Revisar um caso de entrada inválida e demonstrar o fluxo desenvolvido.

## AVALIAÇÃO

Aula 1: estrutura executável e interação com função/lista. Aula 2: fluxo de interface e dados integrado ou com pendências claramente registradas.

## RECOMPOSIÇÃO DE APRENDIZAGEM

Começar com formulário e lista pequenos. Construir primeiro a função de exibição e depois integrar a entrada de dados.

## OBSERVAÇÕES

As aulas são práticas e dão continuidade ao trabalho final explicado na primeira aula de Banco de Dados.
