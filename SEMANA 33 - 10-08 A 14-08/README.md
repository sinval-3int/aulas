# Semana 33 (10/08 a 14/08) — 3º Ano Integral

Material de aula da Semana 33. Foco: **Estrutura Condicional em JavaScript (if / else / else if)** e **declaração de variáveis**, agora integrados diretamente ao HTML/CSS do site que cada aluno já vem construindo (tríade HTML + CSS + JS, sem Node.js/terminal), com o mesmo conceito de decisão condicional testado nas demais disciplinas.

## Conteúdo

- **[Resumo-Semana-33-Alunos.md](Resumo-Semana-33-Alunos.md)** — Resumo da semana para os alunos, dia a dia (WHERE do SQL, if/else em JS ligado ao HTML, testes de conectividade com/sem cabo/internet, npm, tríade HTML/CSS/JS).
- **[Planejamento/](Planejamento/)** — Planejamento do professor por disciplina: Banco de Dados, Design, Diretrizes DED+, Laboratório de Hardware, Laboratório de Software, Laboratório Web, Programação Web II e Rede de Computadores. As aulas teóricas (Banco de Dados, Rede, Laboratório de Hardware, Laboratório de Software, Programação Web II) trazem, ao final de cada arquivo, um prompt pronto para gerar slides no NotebookLM.
- **[ProgWebII/](ProgWebII/README.md)** — Material da aula de Estrutura Condicional (if/else/else if) integrada ao HTML/CSS do protótipo, prompt para gerar slides no NotebookLM, e a **atividade avaliativa "Variáveis, Cálculos e Estrutura Condicional em JavaScript"** (10 exercícios, publicada como campo no Google Sala de Aula).

## Destaques da semana

- **Sem Node.js/terminal**: o JavaScript passa a ser ligado via `<script src="script.js"></script>` ao HTML já existente.
- **Hardware x Rede**: mesmo teste de if/else em duas camadas — cabo de rede conectado/desconectado (Laboratório de Hardware) e requisição com/sem internet na aba Network (Rede de Computadores).
- **Laboratório de Software**: fechamento com revisão de módulos npm, `.gitignore` e envio do projeto ao GitHub.
- **Design/Laboratório Web**: junção da tríade HTML + CSS + JS no protótipo pessoal, sem Media Queries.
