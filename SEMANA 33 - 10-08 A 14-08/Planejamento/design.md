Componente Curricular: Design

Turma(s): 3º Ano Integral

Período previsto: 10/08 a 14/08 (Semana 33)

CONTEÚDO / TEMA DA AULA
Junção da tríade HTML + CSS + JavaScript: ligação de um arquivo script.js ao protótipo de site já desenvolvido pelo aluno, com um primeiro exemplo de if/else manipulando a própria página (sem Media Queries).

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Integrar HTML, CSS e JavaScript em um mesmo projeto, ligando um script externo à página e utilizando estrutura condicional para alterar o conteúdo exibido.

DESENVOLVIMENTO DAS AULAS (1 aula)
Aula 1 (Quinta-feira, 07:00h - Sala de Aula / Prática):
Resumo para o quadro (Para cópia dos alunos):
"1. Tríade do projeto: HTML (estrutura), CSS (estilo) e JavaScript (comportamento) — os três arquivos juntos.
2. Ligar o JavaScript: <script src=\"script.js\"></script>, antes de </body>, no index.html.
3. document.getElementById('id') busca um elemento do HTML pelo id; .innerHTML ou .textContent muda o que aparece na página.
4. Primeiro exemplo: um botão que, com if/else, muda um texto da própria página conforme uma condição."
Descrição da aula: Cada aluno cria o arquivo script.js dentro da pasta do próprio protótipo, liga ao index.html e implementa um primeiro exemplo simples de if/else (ex: um botão que verifica um valor digitado e altera um texto/cor de um elemento existente da página), sem mexer em Media Queries.

AVALIAÇÃO
Avaliação contínua através da correta ligação do script.js ao HTML e do funcionamento do exemplo de if/else implementado por cada aluno.

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, montar junto, passo a passo, a ligação script.js → HTML e um exemplo mínimo de if/else (ex: mudar a cor de um texto ao clicar em um botão), antes de pedir que o aluno repita sozinho no próprio protótipo.

OBSERVAÇÕES:
Aula inaugura, no protótipo de cada aluno, a integração prática de JavaScript (if/else e variáveis) sobre o HTML/CSS já existente — mesmo conteúdo teórico visto em Programação Web II na mesma semana. Media Queries não são trabalhadas nesta aula.
