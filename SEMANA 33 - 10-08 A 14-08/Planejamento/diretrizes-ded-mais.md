## Resumos para o DED+ (Semana 33: 10/08 a 14/08)

```
Resumos para o DED+ (Semana 33: 10/08 a 14/08)
Banco de Dados

Banco de Dados | Segunda-feira (07:00 - 07:50) - Aula teórica. Coluna de tabela como equivalente da variável em JavaScript.

Banco de Dados | Segunda-feira (13:20 - 14:10) - Aula prática. Cláusula WHERE do SQL como estrutura condicional (comparação com o if/else de JavaScript).

Rede de Computadores

Rede de Computadores | Segunda-feira (14:10 - 15:00) - Aula teórica. A aba Network como teste prático de if/else: sucesso ou falha de uma requisição.

Rede de Computadores | Quarta-feira (14:10 - 15:00) - Aula prática. Experimento com/sem internet: comparação entre requisição bem-sucedida (status 200) e requisição com erro na aba Network.

Rede de Computadores | Quarta-feira (15:15 - 16:05) - Aula de Dúvidas e Fixação de Conteúdo.

Programação WEB II

Programação WEB II | Segunda-feira (15:15 - 16:05) - Aula teórica. Estrutura condicional em JavaScript (if/else/else if) integrada ao HTML/CSS do protótipo, via document.getElementById.

Programação WEB II | Sexta-feira (13:20 - 14:10) - Aula de Dúvidas e Fixação de Conteúdo. Prática de if/else/else if integrada ao protótipo (par/ímpar, maioridade, aprovado/recuperação/reprovado).

Laboratório de Hardware

Laboratório de Hardware | Terça-feira (09:45 - 10:35) - Aula teórica. Conexão de rede (cabo conectado ou não) como estrutura de decisão (if/else) em hardware.

Laboratório de Hardware | Quarta-feira (13:20 - 14:10) - Aula prática. Teste de conectividade com o cabo de rede conectado e desconectado.

Laboratório de Software

Laboratório de Software | Terça-feira (10:35 - 11:25) - Aula teórica. npm: o que é, para que serve e instalação de módulos diferentes.

Laboratório de Software | Sexta-feira (15:15 - 16:05) - Aula de Dúvidas e Fixação de Conteúdo. Revisão de módulos instalados, criação de .gitignore e envio do projeto ao GitHub.

Design

Design | Quinta-feira (07:00 - 07:50) - Aula prática. Integração de script.js ao protótipo de site (tríade HTML + CSS + JS) com primeiro exemplo de if/else.

Laboratório Web

Laboratório Web | Quinta-feira (08:40 - 09:30) - Aula prática. Aplicação da integração HTML/CSS/JS (if/else) em todas as páginas do protótipo de site.

Laboratório Web | Sexta-feira (14:10 - 15:00) - Aula de Dúvidas e Fixação de Conteúdo. Exercícios práticos de HTML/CSS/JS com foco em if/else.
```
