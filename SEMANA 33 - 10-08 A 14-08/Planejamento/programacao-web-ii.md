CONTEÚDO / TEMA DA AULA
Estrutura condicional em JavaScript: if, if/else e if/else if/else, integrados diretamente ao HTML/CSS do protótipo de site que cada aluno já vem construindo (sem Node/terminal).

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Declarar e interpretar estruturas condicionais (if/else/else if) em JavaScript, ligando um arquivo script.js a uma página HTML já existente e manipulando seus elementos via document.getElementById.

DESENVOLVIMENTO DAS AULAS (2 aulas)
Aula 1 (Segunda-feira, 15:15h - Sala de Aula / Teórica):
Resumo para o quadro (Para cópia dos alunos, retomado de aula3-js-if-else.md):
"1. script.js se conecta ao HTML com <script src=\"script.js\"></script>, antes de </body>.
2. document.getElementById('id').value lê o que o usuário digitou em um <input>.
3. if (condição) { bloco } — executa o bloco se a condição for true.
4. if (condição) { bloco } else { bloco } — um dos dois blocos sempre executa.
5. if (condição1) { } else if (condição2) { } else { } — testa em ordem, a primeira verdadeira vence."
Descrição da aula: Apresentação da sintaxe de if, if/else e if/else if/else usando o material aula3-js-if-else.md, com exemplos ao vivo lendo um valor digitado em um <input> do próprio HTML (idade, média final) e escrevendo o resultado em um elemento da página via document.getElementById, sem uso de terminal.

Aula 2 (Sexta-feira, 13:20h - Sala de Aula / Aula de Dúvidas e Fixação de Conteúdo):
Resumo para o quadro (Para cópia dos alunos):
"1. Retomada: if, if/else, if/else if/else — sintaxe e ordem de avaliação das condições.
2. document.getElementById('id') busca o elemento no HTML; .value lê o conteúdo de um input; .innerHTML escreve o resultado na página."
Descrição da aula: Material de apoio: aula3-js-if-else.md e exercicios-semana33-formatado.txt (10 exercícios: variáveis, cálculos e estrutura condicional). Início, em aula, da resolução dos exercícios, publicados como atividade no Google Sala de Aula, com esclarecimento de dúvidas dos alunos. Resolução continua ao longo da semana, diretamente no campo da atividade no Google Sala de Aula.

AVALIAÇÃO
Avaliação através do acompanhamento da integração script.js/HTML (Aula 1) e das respostas enviadas no campo da atividade "Variáveis, Cálculos e Estrutura Condicional em JavaScript" no Google Sala de Aula (exercicios-semana33-formatado.txt).

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, refazer em conjunto o exercício de aprovado/recuperação/reprovado, testando uma condição de cada vez e mostrando, na própria página, por que a ordem das condições muda o resultado exibido.
