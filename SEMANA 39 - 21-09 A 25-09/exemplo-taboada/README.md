# Exemplo - Taboada

Exemplo básico de HTML, CSS e JavaScript trabalhando juntos.

## Arquivos
- `index.html` — estrutura da página, com um input de número e um botão
- `style.css` — estilização simples da página
- `script.js` — lógica que lê o número digitado e monta a taboada (1 a 10) na tela
- `prompt-notebooklm-slides.md` — prompt pronto para gerar, no NotebookLM, slides explicando linha por linha este exemplo (e uma versão mais simples, sem loop)

## Como usar
Abra o `index.html` no navegador, digite um número e clique em "Gerar".
