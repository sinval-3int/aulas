DESENVOLVIMENTO DAS AULAS (1 aula)
Aula 1 (Quinta-feira, 07:00h - Sala de Aula / Expositiva, conteúdo novo):
Resumo para o quadro:
"1. Frequência = quantas vezes um valor aparece.
2. Contador: var cont = 0; for (...) { if (lista[i] === alvo) { cont++; } }.
3. Frequência de todos: objeto contador — freq[item] = (freq[item] || 0) + 1.
4. Valores únicos: [...new Set(lista)]; quantidade de únicos: new Set(lista).size.
5. Listas: indexOf, includes, pop, slice (extras)."
Descrição da aula: Exclusivamente expositiva: aplicação de listas e conjuntos ao problema de frequência, com exemplos do professor. Sem exercícios. Prompt de slides em Prompts/prompts-notebooklm.md (Aula 3).
