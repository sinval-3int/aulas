DESENVOLVIMENTO DAS AULAS (2 aulas)
Aula 1 (Quinta-feira, 08:40h - Sala de Aula / Expositiva, conteúdo novo):
Resumo para o quadro:
"1. while (condição) { bloco } — repete enquanto a condição for verdadeira.
2. Preparar a variável antes; alterá-la dentro do bloco; senão o laço é infinito.
3. for: número de voltas conhecido. while: número de voltas desconhecido.
4. break interrompe o laço."
Descrição da aula: Exclusivamente expositiva: sintaxe do while, comparação com for, exemplos do professor e erro do laço infinito. Sem exercícios. Prompt de slides em Prompts/prompts-notebooklm.md (Aula 4).

Aula 2 (Sexta-feira, 14:10h - Laboratório / Prática):
Descrição da aula: Prática de integração no site pré-criado: exibir listas em <ul> estilizada, contar frequência, usar Set e while. Exercícios no Google Sala de Aula.
