CONTEÚDO / TEMA DA AULA
Onde o Código Roda de Verdade: a relação entre o JavaScript executado no navegador e os componentes físicos (CPU e memória RAM) do computador.

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Relacionar o consumo de recursos de hardware (processamento e memória) com a execução de scripts no navegador.

DESENVOLVIMENTO DAS AULAS (2 aulas)
Aula 1 (Terça-feira, 09:45h - Sala de Aula / Teórica):
Resumo para o quadro (Para cópia dos alunos):
"1. O Motor por trás do JavaScript: cada navegador tem um 'motor' (engine) de JavaScript que traduz o código em instruções que o processador (CPU) executa.
2. Papel da CPU: quanto mais cálculos e interações o script realiza, mais trabalho é enviado ao processador.
3. Papel da RAM: enquanto a página está aberta, as variáveis criadas pelo JavaScript ficam guardadas temporariamente na memória RAM do computador.
4. Consequência prática: muitas abas abertas, cada uma rodando seus próprios scripts, aumentam o consumo de RAM e podem deixar o computador lento."
Atividade Teórica: Retomando os componentes de hardware já estudados (CPU, RAM), os alunos relacionarão, em grupo, cada componente com a etapa correspondente da execução de um script JavaScript no navegador.

Aula 2 (Quarta-feira, 13:20h - Sala de Aula / Teórica):
Resumo para o quadro (Para cópia dos alunos):
"5. Testando na Prática: é possível observar, pelo Gerenciador de Tarefas do sistema operacional, quanta memória RAM cada aba do navegador está consumindo.
6. Hardware Adequado: um computador com pouca RAM pode travar ao abrir páginas com muitos scripts JavaScript rodando ao mesmo tempo — por isso, a especificação de hardware de um equipamento também define a qualidade da experiência web."
Atividade de Fixação: Utilizando o Gerenciador de Tarefas, os alunos abrirão duas ou três abas do navegador e registrarão no caderno o consumo de memória de cada uma, relacionando com a quantidade de scripts carregados em cada página.

AVALIAÇÃO
Avaliação contínua através da correção da relação componente-de-hardware/etapa-de-execução (Aula 1) e do registro de consumo de memória no Gerenciador de Tarefas (Aula 2).

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, desenhar no quadro um esquema simples: CPU → RAM → Navegador → Script, materializando o caminho que o código percorre dentro da máquina.

OBSERVAÇÕES:
Aula conecta diretamente com o conteúdo de Introdução ao JavaScript trabalhado em Programação Web II nesta mesma semana.
