Período previsto: 27/07 a 31/07 (Semana 31)

CONTEÚDO / TEMA DA AULA
Projeto Rádio Interativa da Escola: organização das tarefas e versionamento dos layouts e informativos do site.

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Planejar, em equipe, o desenvolvimento de um projeto real e versionar seus artefatos de design em repositório.

DESENVOLVIMENTO DAS AULAS (2 aulas)
Aula 1 (Quinta-feira, 08:40h - Sala de Aula / Teórica):
Resumo para o quadro (Para cópia dos alunos):
"1. O Projeto: a Rádio Interativa da escola precisa de um site com informativos e de uma interface interativa, construídos em equipe.
2. Retomada de Metodologias Ágeis: o quadro Kanban organiza o trabalho em colunas (A Fazer, Fazendo, Feito).
3. Novas Tarefas: com os layouts prontos em Design, surgem tarefas como 'montar página do informativo X' ou 'organizar seção da programação da rádio'.
4. Divisão de Trabalho: cada integrante do grupo assume uma ou mais tarefas do projeto, evitando retrabalho."
Atividade Teórica: Cada grupo organizará, no quadro Kanban do projeto, os cartões de tarefa referentes à construção do site e da interface interativa da Rádio Interativa, a partir dos layouts criados em Design, distribuindo-os entre os integrantes.

Aula 2 (Sexta-feira, 14:10h - Sala de Aula / Prática):
Resumo para o quadro (Para cópia dos alunos):
"5. Versionando o Projeto: os layouts e informativos produzidos em Design são organizados em pastas dentro do projeto e enviados ao repositório.
6. Fluxo de sempre: git add (seleciona os arquivos), git commit (registra a alteração com uma mensagem), git push (envia para o repositório remoto)."
Atividade Prática: Cada grupo organizará os arquivos dos layouts e informativos da Rádio Interativa dentro do projeto e executará o fluxo completo (add, commit, push) para versioná-los, movendo os cartões correspondentes no Kanban para 'Feito'.

AVALIAÇÃO
Avaliação contínua através da organização do quadro Kanban (Aula 1) e da execução correta do fluxo git add/commit/push sobre os arquivos do projeto (Aula 2).

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, acompanhar individualmente o fluxo git no terminal, apontando cada comando digitado e o efeito imediato no repositório.

OBSERVAÇÕES:
Aulas dedicadas ao projeto da Rádio Interativa da escola, em conjunto com Design nesta mesma semana.
