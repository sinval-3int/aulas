CONTEÚDO / TEMA DA AULA
Introdução ao JavaScript: o que é, de onde veio e como inserir o código dentro de uma página HTML.

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Reconhecer o JavaScript como linguagem de programação do lado cliente e identificar as formas de inserção de scripts em um documento HTML.

DESENVOLVIMENTO DAS AULAS (2 aulas)
Aula 1 (Segunda-feira, 15:15h - Sala de Aula / Aula de Dúvidas e Fixação de Conteúdo):
Atividade fixa da semana: retomada de HTML semântico, CSS (Box Model, Flexbox) e formulários já trabalhados, resolução de dúvidas dos alunos antes da entrada em JavaScript.

Aula 2 (Sexta-feira, 13:20h - Sala de Aula / Teórica):
Resumo para o quadro (Para cópia dos alunos):
"1. O que é JavaScript: linguagem de programação que roda no navegador (lado cliente), permitindo interagir com a página (cliques, alertas, validações, animações).
2. História: criada em 1995 pela Netscape com o nome LiveScript, depois renomeada para JavaScript por estratégia de marketing — JavaScript NÃO é Java.
3. Características: tipagem dinâmica (não é preciso declarar o tipo da variável) e interpretada (executa linha a linha no navegador).
4. Onde é usado: sites, apps mobile, aplicações desktop e até no servidor (Node.js).
5. Como inserir no HTML: código entre as tags <script> e </script>, podendo ficar no <head> ou no <body>.
6. JS interno x JS externo: <script>código</script> direto no HTML, ou <script src=\"script.js\"></script> apontando para um arquivo separado.
7. Estrutura de projeto: index.html + style.css (importado no <head> via <link>) + script.js (importado no fim do <body> via <script src>)."
Atividade Teórica: O professor projetará o código HTML do formulário da Startup (mesmo projeto usado em Banco de Dados). Os alunos identificarão onde e como inserir a tag <script> nesse arquivo, anotando no caderno a diferença entre JS interno e externo.

AVALIAÇÃO
Avaliação contínua através da cópia do resumo do quadro e da correta identificação, no código do formulário, de onde inserir a tag <script> (interno x externo).

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, recriar no quadro a estrutura de pastas do projeto (index.html, style.css, script.js) ligando cada arquivo à tag correspondente que o importa no HTML.
