Professor(a): Sinval Silva Júnior

Componente Curricular: Design

Turma(s): 3º Ano Integral

Período previsto: 27/07 a 31/07 (Semana 31)

CONTEÚDO / TEMA DA AULA
Projeto Rádio Interativa da Escola: criação de designs e layouts para os informativos do site e para a interface interativa do projeto.

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Desenvolver layouts e peças de comunicação visual aplicando princípios de UI/UX a um projeto real da escola.

DESENVOLVIMENTO DAS AULAS (1 aula)
Aula 1 (Quinta-feira, 07:00h - Sala de Aula / Prática):
Resumo para o quadro (Para cópia dos alunos):
"1. O Projeto: a Rádio Interativa da escola precisa de um site com informativos e de uma interface interativa para os alunos acompanharem a programação.
2. Papel do Design: antes de qualquer código, o layout define como as informações (notícias, programação, avisos) vão aparecer na tela.
3. Retomada de UI/UX: grid, tipografia e cores devem seguir uma identidade visual única em todas as peças do projeto.
4. Do Papel para o Protótipo: cada informativo do site vira uma tela ou seção dentro do protótipo de layout."
Atividade Prática: Os alunos, em grupo, criarão os designs e layouts dos informativos do site da Rádio Interativa, além do layout da interface interativa do projeto, mantendo consistência visual entre as peças.

AVALIAÇÃO
Avaliação contínua através da qualidade e da consistência visual dos layouts produzidos para os informativos e para a interface interativa do projeto.

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, retomar individualmente os princípios de grid e hierarquia visual sobre um dos layouts já iniciados pelo grupo.

OBSERVAÇÕES:
Aula prática dedicada ao projeto da Rádio Interativa da escola, em conjunto com Laboratório Web nesta mesma semana.
