CONTEÚDO / TEMA DA AULA
O Ambiente que Executa o Código: o papel do Sistema Operacional e do navegador na interpretação do JavaScript.

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Compreender a relação entre Sistema Operacional, navegador e execução de scripts, incluindo a possibilidade de rodar JavaScript fora do navegador.

DESENVOLVIMENTO DAS AULAS (2 aulas)
Aula 1 (Terça-feira, 10:35h - Sala de Aula / Teórica):
Resumo para o quadro (Para cópia dos alunos):
"1. O Papel do Sistema Operacional: o navegador é apenas mais um aplicativo (processo) gerenciado pelo Sistema Operacional, que aloca CPU e memória para ele funcionar.
2. Dentro do Aplicativo: dentro do navegador, o motor de JavaScript interpreta e executa o código do site.
3. JavaScript fora do navegador: o Node.js é um ambiente que permite executar código JavaScript diretamente no Sistema Operacional, via linha de comando, sem precisar de navegador.
4. Retomada de Terminal: os comandos básicos de terminal já estudados (navegação, execução de comandos) são os mesmos usados para rodar um script JavaScript com Node.js."
Atividade Teórica: Utilizando o Gerenciador de Tarefas/Monitor de Sistema, os alunos localizarão o processo do navegador em execução e discutirão em grupo por que ele aparece como um processo do Sistema Operacional, assim como qualquer outro programa.

Aula 2 (Sexta-feira, 15:15h - Sala de Aula / Aula de Dúvidas e Fixação de Conteúdo):
Atividade fixa da semana: retomada de virtualização, arquitetura Linux, terminal Bash e do conteúdo da Aula 1, com resolução de dúvidas dos alunos.

AVALIAÇÃO
Avaliação contínua através da participação na identificação do processo do navegador no Gerenciador de Tarefas e da discussão em grupo (Aula 1).

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, desenhar no quadro camadas empilhadas: Hardware → Sistema Operacional → Navegador → Motor JavaScript → Script, materializando onde o código realmente é executado.

OBSERVAÇÕES:
A Aula 2 (sexta-feira, último horário da tarde) é fixa em todas as semanas: dedicada a dúvidas e fixação de conteúdo. O conceito de Node.js apresentado aqui será retomado em semanas futuras quando a disciplina tratar de ambientes virtualizados.
