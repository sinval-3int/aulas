CONTEÚDO / TEMA DA AULA
A Viagem do Código: Como o arquivo JavaScript criado no computador do desenvolvedor chega até o navegador do usuário através da rede.

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Compreender o papel dos meios físicos e lógicos de rede na entrega de arquivos HTML, CSS e JavaScript do servidor até o cliente.

DESENVOLVIMENTO DAS AULAS (3 aulas)
Aula 1 (Segunda-feira, 14:10h - Sala de Aula / Teórica):
Resumo para o quadro (Para cópia dos alunos):
"1. O Pedido (Requisição): Quando o usuário digita um endereço, o navegador faz um pedido (requisição) para um servidor através da rede.
2. A Entrega: O servidor responde enviando os arquivos HTML, CSS e JavaScript, que trafegam em pacotes de dados pela rede até o navegador.
3. Rede Local x Internet: Os mesmos princípios de cabeamento e topologia estudados na disciplina valem tanto para uma rede local (LAN) quanto para a internet, mudando apenas a escala.
4. Consequência prática: Quanto maior o arquivo JavaScript, mais pacotes de dados precisam trafegar pela rede até chegarem ao usuário."
Atividade Teórica: Em grupo, os alunos desenharão no caderno um diagrama simples representando o trajeto de um arquivo script.js desde o servidor até o navegador do cliente, indicando os equipamentos de rede envolvidos.

Aula 2 (Quarta-feira, 14:10h - Sala de Aula / Teórica-Prática):
Resumo para o quadro (Para cópia dos alunos):
"5. Retomada de Cabeamento: Cabos de par trançado (UTP) e conectores RJ45 continuam sendo o meio físico mais comum para levar esses dados dentro de uma rede local.
6. Latência: É o tempo que um pacote de dados leva para ir e voltar entre dois pontos da rede — quanto maior a latência, mais lento o carregamento de uma página com JavaScript pesado."
Atividade Prática: Execução de testes de Ping entre as bancadas do laboratório, relacionando o tempo de resposta obtido com a velocidade de carregamento de uma página web.

Aula 3 (Quarta-feira, 15:15h - Sala de Aula / Aula de Dúvidas e Fixação de Conteúdo):
Atividade fixa da semana: retomada dos conceitos vistos nas Aulas 1 e 2, resolução de dúvidas dos alunos e exercícios de fixação sobre o trajeto dos dados na rede.

AVALIAÇÃO
Avaliação contínua através da correção do diagrama do trajeto do arquivo (Aula 1) e da participação nos testes práticos de Ping (Aula 2).

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, desenhar no quadro uma seta única ligando o ícone do "Servidor" ao ícone do "Navegador", passando pelos equipamentos de rede (switch, roteador), materializando o caminho físico do dado.

OBSERVAÇÕES:
A Aula 3 (quarta-feira, último horário da tarde) é fixa em todas as semanas: dedicada a dúvidas e fixação de conteúdo.
