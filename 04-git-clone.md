# Como baixar um projeto do GitHub (Git Clone)

## 1. Copie a URL do repositório

Exemplo:

```text
https://github.com/sinval-3int/aulas.git
```

## 2. Clone o projeto

```bash
git clone https://github.com/usuario/repositorio.git
```

## 3. Entre na pasta

```bash
cd aulas
```

## Fluxo de trabalho

```bash
git pull
git add .
git commit -m "Descrição da alteração"
git push
```
