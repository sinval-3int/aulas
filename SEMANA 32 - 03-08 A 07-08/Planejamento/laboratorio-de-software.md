CONTEÚDO / TEMA DA AULA
Continuação: Node.js como ambiente de execução de JavaScript fora do navegador, a partir da introdução feita na Semana 31.

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Reconhecer o funcionamento básico do Node.js e retomar, na prática, o uso do terminal para executar comandos e scripts.

DESENVOLVIMENTO DAS AULAS (2 aulas)
Aula 1 (Terça-feira, 10:35h - Sala de Aula / Teórica):
Resumo para o quadro (Para cópia dos alunos):
"1. Retomada: Node.js é um ambiente que executa JavaScript fora do navegador, direto no Sistema Operacional.
2. Por que existe: permite usar a mesma linguagem (JavaScript) tanto no front-end (navegador) quanto em tarefas de linha de comando ou servidor.
3. Como se usa: um arquivo .js é executado no terminal com o comando node arquivo.js.
4. Retomada de terminal: navegação entre pastas (cd) e listagem de arquivos (ls/dir) são a base para localizar e rodar um script."
Atividade Teórica: Em grupo, os alunos relacionarão os comandos de terminal já estudados (navegação, listagem) com os passos necessários para localizar e executar um arquivo JavaScript via Node.js, sem ainda executar (preparação para a fixação de sexta-feira).

Aula 2 (Sexta-feira, 15:15h - Sala de Aula / Aula de Dúvidas e Fixação de Conteúdo):
Resumo para o quadro (Para cópia dos alunos):
"1. Navegador é um processo gerenciado pelo Sistema Operacional, como qualquer outro programa.
2. Node.js executa JavaScript fora do navegador, direto no Sistema Operacional.
3. Para executar: abrir terminal → navegar até a pasta do arquivo (cd) → digitar node arquivo.js."
Descrição da aula: Atividade fixa da semana. Revisão oral do resumo com apoio do quadro, exercício de simulação do caminho completo (localizar pasta → comando node) e resolução de dúvidas dos alunos sobre Sistema Operacional, terminal e Node.js (Semanas 31 e 32).

AVALIAÇÃO
Avaliação contínua através da participação na relação comandos de terminal x execução de script (Aula 1) e do engajamento na revisão da Aula 2.

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, escrever no quadro passo a passo o caminho completo: abrir terminal → navegar até a pasta do arquivo (cd) → digitar node arquivo.js.

OBSERVAÇÕES:
A Aula 2 (sexta-feira, último horário da tarde) é fixa em todas as semanas: dedicada a dúvidas e fixação de conteúdo, funcionando nesta semana também como o "resumão" de Sistema Operacional/Node.js.
