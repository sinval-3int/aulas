Componente Curricular: Design

Turma(s): 3º Ano Integral

Período previsto: 03/08 a 07/08 (Semana 32)

CONTEÚDO / TEMA DA AULA
Sequência da apostila de HTML e CSS: novas tags estruturais/semânticas e aprofundamento de estilização, aplicadas ao layout que o próprio aluno está desenvolvendo.

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Aplicar tags HTML estruturais e propriedades de estilização CSS para transformar um layout visual em uma página real.

DESENVOLVIMENTO DAS AULAS (1 aula)
Aula 1 (Quinta-feira, 07:00h - Sala de Aula / Prática):
Resumo para o quadro (Para cópia dos alunos):
"1. Sequência da apostila: novas tags estruturais (header, nav, main, section, article, footer) organizam o HTML de forma semântica.
2. Do Layout ao Código: cada bloco de um layout corresponde a uma dessas tags.
3. Retomada e aprofundamento de CSS: seletores, Box Model e cores aplicados para aproximar a página do layout planejado."
Descrição da aula: Os alunos, individualmente, avançam na marcação HTML do próprio protótipo de site (exercício contínuo da apostila), usando as tags estruturais apresentadas, e aplicam estilização CSS (cores, espaçamento, Box Model) buscando fidelidade ao layout que cada um vem planejando.

AVALIAÇÃO
Avaliação contínua através da correta aplicação das tags estruturais e da fidelidade visual entre o código produzido e o layout planejado por cada aluno.

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, marcar junto, tag por tag, qual elemento do layout corresponde a cada tag estrutural (header, nav, main, footer).

OBSERVAÇÕES:
Aula prática dedicada à sequência da apostila de HTML/CSS, em conjunto com Laboratório Web nesta mesma semana. Sem vínculo com o Projeto Rádio Interativa (projeto conduzido por outro professor, concluído na segunda-feira).
