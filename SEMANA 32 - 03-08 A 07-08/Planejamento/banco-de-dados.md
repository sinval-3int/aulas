Componente Curricular: Banco de Dados

Turma(s): 3º Ano Integral

Período previsto: 03/08 a 07/08 (Semana 32)

CONTEÚDO / TEMA DA AULA
Semana atípica: segunda-feira integral dedicada ao Projeto Rádio Interativa da Escola. Sem conteúdo técnico novo de Banco de Dados nesta semana.

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Planejar, em equipe, quais informações de um projeto real precisam ser organizadas e futuramente armazenadas.

DESENVOLVIMENTO DAS AULAS (2 aulas)
Aula 1 (Segunda-feira, 07:00h - Sala de Aula / Prática - Projeto):
Resumo para o quadro (Para cópia dos alunos):
"1. Retomada: dado temporário (JavaScript, na memória do navegador) x dado permanente (Banco de Dados).
2. Nesta semana: antes de criar tabelas, é preciso levantar QUAIS informações de cada informativo da Rádio Interativa precisam existir (título, texto, data, responsável).
3. Esse levantamento é o primeiro passo de qualquer Banco de Dados real, antes de qualquer comando SQL."
Descrição da aula: Os grupos, a partir dos layouts prontos em Design (Semana 31), levantarão quais informações de cada informativo do site da Rádio Interativa precisarão futuramente ser guardadas, sem ainda formalizar tabelas ou SQL — retomando o vocabulário de dado permanente x temporário visto na Semana 31.

Aula 2 (Segunda-feira, 13:20h - Sala de Aula / Prática - Projeto):
Resumo para o quadro (Para cópia dos alunos):
"4. Continuidade: cada informação levantada na Aula 1 vira um campo em uma lista organizada (ex: título, texto, data, responsável).
5. Essa lista de campos é o rascunho do que, futuramente, vai virar coluna de tabela em SQL."
Descrição da aula: Continuidade do trabalho da Aula 1: cada grupo organiza, em uma lista simples no caderno ou planilha, os campos de informação levantados para os informativos e para a programação da rádio, servindo de insumo para quando o conteúdo formal de tabelas/SQL for retomado em semanas futuras.

AVALIAÇÃO
Avaliação contínua através da participação no levantamento de informações do projeto e da qualidade da lista de campos produzida pelos grupos.

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, auxiliar individualmente a transformar um informativo já pronto (do layout de Design) em uma lista simples de "o que esse informativo precisa guardar".

OBSERVAÇÕES:
Semana sem aula técnica nova de Banco de Dados. As duas aulas da segunda-feira (07:00 e 13:20) são convertidas em trabalho prático do Projeto Rádio Interativa, junto com Rede de Computadores e Programação WEB II no mesmo dia.
