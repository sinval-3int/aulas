Professor(a): Sinval Silva Júnior

Componente Curricular: Laboratório WEB

Turma(s): 3º Ano Integral

Período previsto: 03/08 a 07/08 (Semana 32)

CONTEÚDO / TEMA DA AULA
Quinta-feira: sequência da apostila de HTML/CSS aplicada à construção do protótipo de site do próprio aluno. Sexta-feira: fixação prática de HTML/CSS.

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Construir páginas HTML/CSS a partir de um layout definido, organizando os arquivos do próprio protótipo.

DESENVOLVIMENTO DAS AULAS (2 aulas)
Aula 1 (Quinta-feira, 08:40h - Sala de Aula / Prática):
Resumo para o quadro (Para cópia dos alunos):
"1. Continuidade: a marcação HTML e estilização CSS iniciadas em Design (mesma manhã) são finalizadas e organizadas em pasta do próprio projeto do aluno.
2. Organização de arquivos: index.html, style.css e (quando houver) script.js na mesma pasta."
Descrição da aula: Cada aluno continua, no laboratório, a construção HTML/CSS do próprio protótipo de site iniciado em Design, organizando os arquivos (index.html, style.css) dentro de uma pasta do projeto pessoal.

Aula 2 (Sexta-feira, 14:10h - Sala de Aula / Aula de Dúvidas e Fixação de Conteúdo):
Resumo para o quadro (Para cópia dos alunos):
"1. Retomada: tags estruturais (header, nav, main, section, article, footer).
2. Retomada: seletores CSS e Box Model (margin, border, padding, content)."
Descrição da aula: Atividade fixa da semana. Exercícios práticos de fixação de HTML/CSS (tags estruturais, seletores, Box Model), independentes do protótipo pessoal, para consolidar a apostila antes de seguir para o próximo bloco de conteúdo, com esclarecimento de dúvidas dos alunos.

AVALIAÇÃO
Avaliação contínua através do progresso das páginas HTML/CSS do protótipo pessoal e da organização dos arquivos (Aula 1), e da resolução dos exercícios de fixação (Aula 2).

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, refazer com acompanhamento individual um dos exercícios de fixação de HTML/CSS da Aula 2, tag por tag.

OBSERVAÇÕES:
A Aula 1 (quinta-feira) segue direto de Design, no mesmo dia. A Aula 2 (sexta-feira) é a aula fixa de dúvidas e fixação de conteúdo, dedicada esta semana a exercícios de HTML/CSS. Sem vínculo com o Projeto Rádio Interativa (projeto conduzido por outro professor, concluído na segunda-feira).
