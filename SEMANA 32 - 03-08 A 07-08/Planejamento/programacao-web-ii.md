CONTEÚDO / TEMA DA AULA
Segunda-feira: Projeto Rádio Interativa da Escola (levantamento de elementos dinâmicos da interface). Sexta-feira: fixação prática de Variáveis e Operadores em JavaScript.

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Declarar variáveis, aplicar operadores matemáticos, de comparação e lógicos em JavaScript, e reconhecer, em um projeto real, quais elementos de interface poderão futuramente ser manipulados via script.

DESENVOLVIMENTO DAS AULAS (2 aulas)
Aula 1 (Segunda-feira, 15:15h - Sala de Aula / Prática - Projeto):
Resumo para o quadro (Para cópia dos alunos):
"1. Retomada: elemento dinâmico é aquele que muda na tela sem recarregar a página (ex: destacar notícia, tocar player, atualizar lista).
2. Nesta semana: mapear, nos layouts prontos em Design, quais elementos da interface da Rádio Interativa serão futuramente controlados por JavaScript."
Descrição da aula: Os grupos, junto com Banco de Dados e Rede de Computadores, avançam no Projeto Rádio Interativa. Contribuição de Programação WEB II: a partir dos layouts prontos em Design, levantar quais elementos da interface (ex: destaque de notícia, player, lista de programação) serão futuramente dinâmicos/interativos via JavaScript.

Aula 2 (Sexta-feira, 13:20h - Sala de Aula / Aula de Dúvidas e Fixação de Conteúdo):
Resumo para o quadro (Para cópia dos alunos, retomado de aula2-js-quadro.md):
"1. Variável guarda um valor por vez; JS não exige tipo declarado (var nome = valor;).
2. Tipos: numéricas, booleanas (true/false), strings ('...' ou \"...\"); null representa valor vazio/desconhecido.
3. Operadores matemáticos: + - * / ++ -- %
4. Operadores de comparação: > < >= <= == === !=
5. Operadores lógicos: && (E), || (OU), ! (NÃO)."
Descrição da aula: Material de apoio: aula2-js-quadro.md. Retomada dos conteúdos de Variáveis e Operadores em JavaScript, com resolução dos exercícios propostos (média de 3 notas, cálculo de idade, consumo médio de um automóvel) e esclarecimento de dúvidas dos alunos.

AVALIAÇÃO
Avaliação contínua através da contribuição na Aula 1 (Projeto) e da correção dos exercícios de fixação de Variáveis e Operadores (Aula 2).

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, refazer em conjunto um dos exercícios de fixação (Aula 2) passo a passo, identificando variável, operador e resultado em cada linha do script.

OBSERVAÇÕES:
A Aula 1 (segunda-feira) é atípica: dedicada ao Projeto Rádio Interativa, junto com Banco de Dados e Rede de Computadores. A Aula 2 (sexta-feira) é a aula fixa de dúvidas e fixação de conteúdo, usada nesta semana para consolidar Variáveis e Operadores (conteúdo já detalhado em aula-2-variaveis-javascript/).
