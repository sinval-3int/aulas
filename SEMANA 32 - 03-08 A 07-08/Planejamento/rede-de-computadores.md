Componente Curricular: Rede de Computadores

Turma(s): 3º Ano Integral

Período previsto: 03/08 a 07/08 (Semana 32)

CONTEÚDO / TEMA DA AULA
Segunda-feira: Projeto Rádio Interativa da Escola (rede como meio de acesso ao protótipo). Quarta-feira: a aba Network (Rede) das Ferramentas do Desenvolvedor do navegador — inspecionando, na prática, as requisições de HTML, CSS e JavaScript feitas ao carregar o protótipo do site.

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Utilizar a aba Network do navegador para inspecionar, na prática, as requisições de rede (HTML, CSS, JS) envolvidas no carregamento de uma página, relacionando tamanho, tempo e status de cada requisição à experiência de uso.

DESENVOLVIMENTO DAS AULAS (3 aulas)
Aula 1 (Segunda-feira, 14:10h - Sala de Aula / Prática - Projeto):
Resumo para o quadro (Para cópia dos alunos):
"1. Retomada: requisição do navegador → resposta do servidor com HTML/CSS/JS, trafegando em pacotes pela rede.
2. Nesta semana: o protótipo do site da Rádio Interativa também vai precisar ser acessado pelas bancadas do laboratório, dentro da rede local."
Descrição da aula: Os grupos, junto com Banco de Dados e Programação WEB II, avançam no Projeto Rádio Interativa. Contribuição de Rede: levantar como o protótipo do site (ainda em construção) poderá ser acessado pelas bancadas do laboratório dentro da rede local, retomando o trajeto servidor → navegador visto na Semana 31.

Aula 2 (Quarta-feira, 14:10h - Sala de Aula / Prática):
Resumo para o quadro (Para cópia dos alunos):
"1. Ferramentas do Desenvolvedor: no navegador, botão direito → Inspecionar → aba Network (Rede).
2. Ao recarregar a página, essa aba lista cada requisição feita pelo navegador ao servidor: o arquivo HTML, cada arquivo CSS, cada arquivo JS, imagens, etc.
3. Colunas importantes: Name (nome do arquivo), Status (200 = ok, 404 = não encontrado), Type (html/css/js/img), Size (tamanho) e Time (tempo de resposta — a latência de cada requisição, na prática).
4. Aplicação da semana: cada aluno inspeciona o carregamento do próprio protótipo de site (desenvolvido nas aulas de HTML/CSS), identificando quais arquivos foram carregados e o tempo de cada um."
Descrição da aula: Utilizando a aba Network das Ferramentas do Desenvolvedor, cada aluno recarrega o próprio protótipo de site e registra, para cada requisição, o nome do arquivo, o tipo (HTML/CSS/JS), o status e o tempo de resposta, relacionando o resultado com o trajeto servidor → navegador estudado na Semana 31 e com o cabeamento/latência de rede já vistos.

Aula 3 (Quarta-feira, 15:15h - Sala de Aula / Aula de Dúvidas e Fixação de Conteúdo):
Resumo para o quadro (Para cópia dos alunos):
"1. Trajeto do dado: servidor → pacotes de dados → rede → navegador do cliente.
2. Cabeamento: cabo UTP + conector RJ45 como meio físico mais comum da rede local.
3. Aba Network do navegador: mostra, na prática, cada arquivo (HTML/CSS/JS) requisitado, seu tamanho, status e tempo de resposta (latência)."
Descrição da aula: Atividade fixa da semana. Revisão oral dos três pontos do resumo com apoio do quadro, seguida de exercícios de fixação (inspecionar a aba Network de outra página à escolha) e resolução de dúvidas dos alunos sobre os conteúdos de Rede das Semanas 31 e 32.

AVALIAÇÃO
Avaliação contínua através da contribuição na Aula 1 (Projeto), do registro das requisições na aba Network (Aula 2) e do engajamento na revisão da Aula 3.

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, abrir a aba Network junto com o aluno, recarregar a página e apontar, uma a uma, qual linha corresponde ao arquivo HTML, qual ao CSS e qual ao JS.

OBSERVAÇÕES:
A Aula 1 (segunda-feira) é atípica: dedicada ao Projeto Rádio Interativa, junto com Banco de Dados e Programação WEB II. A Aula 3 (quarta-feira, último horário da tarde) é fixa em todas as semanas: dedicada a dúvidas e fixação de conteúdo, e nesta semana funciona também como o "resumão" da semana.
