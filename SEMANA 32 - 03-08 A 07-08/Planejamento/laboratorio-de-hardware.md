Componente Curricular: Laboratório de Hardware

Turma(s): 3º Ano Integral

Período previsto: 03/08 a 07/08 (Semana 32)

CONTEÚDO / TEMA DA AULA
Continuação: hardware e desempenho na execução de JavaScript — do consumo de memória (Semana 31) para o impacto do hardware na experiência de uso de páginas com muitos scripts.

HABILIDADES (BNCC)
(EM13TEC02) Utilizar ferramentas e linguagens de programação para solucionar problemas e criar interfaces. (Competência Técnica) Relacionar a capacidade de processamento e memória de um equipamento com a fluidez de execução de scripts JavaScript, verificando na prática.

DESENVOLVIMENTO DAS AULAS (2 aulas)
Aula 1 (Terça-feira, 09:45h - Sala de Aula / Teórica):
Resumo para o quadro (Para cópia dos alunos):
"1. Retomada: CPU processa as instruções do script, RAM guarda as variáveis enquanto a página está aberta.
2. Hardware limitado: um processador mais lento ou pouca RAM disponível fazem o navegador demorar mais para responder a cliques e animações controladas por JavaScript.
3. Boas práticas do desenvolvedor: evitar scripts desnecessariamente pesados ajuda o site a rodar bem mesmo em máquinas mais simples.
4. Exemplo: um script com muitos cálculos (como os exercícios de variáveis e operadores de Programação WEB II) exige mais processamento do que um script simples."
Atividade Teórica: Em grupo, os alunos listarão, a partir dos scripts de exemplo vistos em Programação WEB II (cálculo de IMC, média de notas, idade), quais operações poderiam pesar mais no processamento (CPU) e na memória (RAM) do equipamento do usuário.

Aula 2 (Quarta-feira, 13:20h - Sala de Aula / Prática):
Resumo para o quadro (Para cópia dos alunos):
"5. Verificação prática: o Gerenciador de Tarefas mostra o consumo de CPU e RAM de cada aba do navegador em tempo real.
6. Comparação: abrir a mesma página com poucos e com muitos scripts/animações permite comparar o consumo de recursos."
Atividade Prática: Utilizando o Gerenciador de Tarefas, os alunos abrirão páginas de exemplo com diferentes quantidades de scripts/animações e registrarão o consumo de CPU e RAM de cada uma, relacionando com a discussão teórica da Aula 1.

AVALIAÇÃO
Avaliação contínua através da lista de elementos dinâmicos x consumo de recursos (Aula 1) e do registro comparativo de CPU/RAM no Gerenciador de Tarefas (Aula 2).

RECOMPOSIÇÃO DE APRENDIZAGEM
Para alunos com dificuldade de abstração, comparar lado a lado, no Gerenciador de Tarefas, uma aba parada e uma aba executando uma animação, apontando a diferença de consumo em tempo real.

OBSERVAÇÕES:
Aula conecta com os scripts de Variáveis e Operadores vistos em Programação WEB II e retoma o conteúdo de CPU/RAM da Semana 31.
