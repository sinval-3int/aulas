# Diretrizes — Resumos para o DED+

Este arquivo define o padrão de escrita dos resumos lançados no sistema DED+ (Diário Eletrônico do Estado), a partir dos planos de aula da Semana 32.

## Estrutura do título do bloco

```
Resumos para o DED+ (Semana [NÚMERO]: [dd/mm] a [dd/mm])
```

## Estrutura por disciplina

1. Nome da disciplina como subtítulo (linha própria).
2. Uma linha por aula lançada, no formato:

```
[Disciplina] | [Dia da semana] ([HH:MM - HH:MM]) - [Descrição curta da aula].
```

## Regras de redação da descrição

- Frase curta, no estilo de resumo administrativo (o que foi feito, não o roteiro didático completo).
- Sempre citar o **tipo de aula** quando fizer diferença: aula prática, aula teórica, aplicação de avaliação escrita, revisão integrativa, aula de dúvidas e fixação de conteúdo.
- Quando for avaliação, citar entre parênteses o **conteúdo cobrado**.
- Quando for aula teórica ou prática, citar o **tema central** de forma objetiva, sem repetir o passo a passo do plano de aula.
- Não copiar o "Resumo para o quadro" nem a "Atividade" na íntegra — o DED+ recebe apenas a síntese.
- Manter a ordem das disciplinas sempre igual, seguindo a ordem dos dias/horários da semana: Banco de Dados, Rede de Computadores, Programação WEB II, Laboratório de Hardware, Laboratório de Software, Design, Laboratório WEB.
- Dentro de cada disciplina, listar as aulas na ordem cronológica da semana (segunda → sexta).
- Toda aula prevista no plano de aula da semana deve ter uma linha correspondente no DED+, inclusive as aulas fixas de dúvidas e fixação de conteúdo.
